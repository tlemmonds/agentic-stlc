# v1.0.0 — 2026-05-15

> Initial baseline. Every scenario currently in `scenarios/scenarios.json`
> is implicitly part of this release. Future releases compare against
> `v1.0.0.lock.json` to compute Add/Edit/Delete operations on the test
> pool (see [RELEASE_NOTES_GUIDE.md](../RELEASE_NOTES_GUIDE.md)).

### Added

- User can add a product to the cart from the product detail page
- User can open the cart dropdown and see the list of added items
- User can navigate to the Laptops product catalog
- User can apply a manufacturer brand filter from the sidebar
- User can click a product thumbnail to open its detail page
- User can browse the homepage and product listings without logging in
- User can search for a product by name using the search bar
- User can register a new account
- User can log in with a registered email address and password
- User can log out from the account
- User can remove an item from the shopping cart
- User can update the quantity of an item in the shopping cart
- User can sort products by price low to high
- User can add a product to the wish list
- User can complete a guest checkout
