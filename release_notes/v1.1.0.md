# [1.1.0] - 2026-05-15

Second release of TaskFlow. Adds labels, changes the
default task sort to surface overdue work, and removes the ability to
delete tasks — items now move to an Archive state and can be restored.

## Added

- User can attach a colored label to a task and filter by label
- User can view archived tasks on the Archive page and restore them to the active list

## Changed

- User can list all tasks ordered by due date, with overdue tasks pinned to the top

## Removed

- User can delete a task (items now move to Archive instead)
