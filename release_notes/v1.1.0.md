# [1.1.0] - 2026-05-15

Second release of No Secret Formula TaskFlow. Adds labels, changes the
default task sort to surface overdue work, and replaces hard-delete with
a soft-delete + Trash workflow.

## Added

- User can attach a colored label to a task and filter by label

## Changed

- User can list all tasks ordered by due date, with overdue tasks pinned to the top

## Removed

- User can delete a task
